WHAT EXISTS TODAY (read before coding; do NOT change any of it):
- bin/ainarres.mjs exports the PURE `formatReport({ board, timeline, trackRecord, governance,
  auditFlags, governanceActions }, { lane })` and `reportJson(...)` with the same signature.
  formatReport already renders a "governance (v5 …):" section (banned / trending / MERGE QUEUE
  HALTED / open audit flags / ⚑ RECOMMEND PERMANENT BAN / governance actions), pure + total.
  The `report` command fetches each view and degrades to [] on error. `fmtTokens(n)` is the
  model pure helper (null → "unknown"; 1234 → "1.2k"; 1_200_000 → "1.2M"). Pure-formatter
  tests live in test/status-format.test.ts.
- `board` rows (already the first formatReport arg, already fetched by `report`) carry
  `task_id`, `stage`, `claimed_by` (nullable), and `abandoned` (boolean). A row with
  `abandoned === true` is a stalled/stranded claim — the HEALTH signal (no new view needed;
  the health watch is a lens over state that already ships, design D4).
- `api.spend_anomalies` — read-only, oversight-scoped. One row per anomaly. Columns:
  `family`, `capability`, `anomaly` ('overspending' | 'no_delivery_spend'),
  `tokens_per_delivery` (numeric, NULL for no_delivery_spend), `peer_median` (numeric, NULL
  for no_delivery_spend), `peer_count` (int, NULL for no_delivery_spend),
  `multiple_over_median` (numeric, NULL for no_delivery_spend), `overspend_multiple` (numeric),
  `delivered` (int), `usage_events` (int).
- `api.operational_flags` — read-only, oversight-scoped, newest-first. Columns: `family` (the
  FLAGGED family), `capability`, `kind` ('spinning' | 'overspending' | 'health' | 'integrity'),
  `detail` (text), `severity` (text), `actor_sub`, `created_at`.

THE CONSEQUENCE LINE (design D5 — render it, decide nothing): the operational facet NEVER
auto-bans. Present each item with a trailing tag: an OVERSPENDING signal is a COST signal, not
competence → tag "(cost)"; everything else (spinning, burned, health, integrity) → tag
"(review)". Overspending must NEVER read as a ban recommendation. This tag is the whole of the
D5 presentation, and it lives HERE in the pure formatter.

   Compute the three groups, then:
